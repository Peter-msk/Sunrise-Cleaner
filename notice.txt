Sunrise Cleaner 공지사항

현재 최신 버전: v3.5.0

- 작업 화면을 안전 정리 및 분석, 드라이브 및 저장장치 건강 진단, 관리자 문제 해결 영역으로 구성했습니다.
- 최근 사용 ActiveX를 보호하고, 등록 해제 성공 후에만 안전 경로의 OCX/DLL을 제거합니다.
- 저장장치 건강 진단은 물리 디스크-드라이브 연결, 최근 오류 이벤트, SSD/NVMe 건강정보, 공간 위험도, 종합등급, 이전 검사 추세를 읽기 전용으로 확인합니다.
- 읽기 전용 진단 자체는 복구를 실행하지 않으며, 점검 후 별도 권장 보완 화면에서 사용자가 직접 선택·확인한 작업만 프로그램이 실행합니다.
- 고위험 저장장치에서는 쓰기성 복구·최적화를 차단하고 백업 우선으로 안내합니다.
- 검사 이력에는 저장장치 일련번호 원문을 저장하지 않고 비식별 해시만 사용합니다.
- 전후 드라이브 용량 변화와 반복 성능 프로필을 비교해 결과를 다시 확인할 수 있습니다.
- 보안 검사는 파일 서명과 Windows Defender 격리 상태를 읽기 전용으로 표시하며, 확인 제한 상태를 성공으로 오인하지 않습니다.
- 사용자가 선택한 일반 파일은 SHA-256 검증 후 사용자 영역 격리함으로 이동하고, 보존 기간 내 복원할 수 있습니다. 복사·검증·삭제 중 실패하면 원본을 보존합니다.
- 예약 검토는 사용자 승인 전용으로 실행되며 자동 삭제·자동 복원을 수행하지 않습니다.
- 핵심 운영 화면에 한국어·영어, 고대비, 스크린 리더 요약, 알림, 설정 내보내기를 제공합니다.
- 공지 조회와 업데이트는 마지막 검증 단계에서 manifest, 다운로드 SHA-256, previous 백업, 성공 후 정리, 실패 원복까지 확인합니다.
