# Sunrise Cleaner

**최신 배포 기준: v3.7.6** · Windows 10/11 x64 · 단일 실행파일(EXE)

Windows의 임시파일과 캐시 등 정리 대상을 검색하고, 사용자가 결과를 확인한 뒤 필요한 항목만 정리하는 데스크톱 프로그램입니다.

## 1. 프로그램 개요
Sunrise Cleaner는 PC의 저장공간을 점검하고 불필요한 파일을 정리하기 위한 도구입니다. 정리 대상별 종류·경로·용량과 처리 결과를 보여주어, 사용자가 삭제 여부를 직접 판단할 수 있도록 설계되었습니다.

## 2. 개발 목적
- 반복적으로 누적되는 임시파일과 캐시의 상태를 쉽게 확인합니다.
- 검색과 삭제를 분리해 필요한 항목만 선택적으로 정리합니다.
- 대량 파일 검색과 정리 중에도 진행상태와 처리 결과를 확인할 수 있게 합니다.
- 기존 사용자 파일과 정상적인 Windows 사용환경을 최대한 보존합니다.

## 3. 주요 기능
- 사용자 임시파일, Windows 임시파일·캐시, 브라우저 캐시 및 휴지통 등의 정리 후보 검색
- 파일 종류·위치·예상 정리 용량 확인 및 선택 삭제
- 중복 파일 및 저장공간 관련 탐색 기능
- 진행률, 작업 결과, 처리하지 못한 항목의 사유 표시
- 저장공간을 이해하기 위한 3D 시각화 기능
- 프로그램 공지와 새 버전 확인

지원 가능한 정리 항목은 Windows 환경과 권한에 따라 달라질 수 있습니다.

## 4. 실행조건
| 항목 | 조건 |
| --- | --- |
| 운영체제 | Windows 10 또는 Windows 11 |
| 시스템 | 64비트(x64) |
| 배포 형식 | `Sunrise_cleaner.exe` 단일 실행파일 |
| 실행 권한 | 일반 권한으로 시작하며, 일부 시스템 작업은 별도 권한이 필요할 수 있음 |
| Python 설치 | 배포 EXE 실행에는 필요 없음 |

## 5. 설치 및 사용방법
1. [Releases](https://github.com/Peter-msk/Sunrise-Cleaner/releases)에서 제공되는 공식 실행파일을 내려받습니다.
2. `Sunrise_cleaner.exe`를 실행합니다.
3. 정리 후보 검색을 진행하고 종류·경로·용량을 검토합니다.
4. 정리하려는 항목을 선택한 뒤 확인 절차에 따라 삭제합니다.
5. 완료 화면에서 성공·건너뜀·실패 결과를 확인합니다.

삭제 전에는 작업 중인 문서를 저장하고, 정리 대상이 필요한 파일인지 확인하세요.
