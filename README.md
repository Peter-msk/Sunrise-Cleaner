# Sunrise Cleaner

Sunrise Group의 Windows 저장공간 점검·파일 정리 프로그램입니다.

## 프로그램 목적

PC에 누적된 임시파일과 캐시 등의 정리 후보를 찾아 종류·경로·용량을 확인하고, 사용자가 필요한 항목만 선택해 안전하게 정리하도록 지원합니다.

## 지원 운영체제

- Windows 10 / Windows 11 (64비트, x64)

## 개발언어 및 주요 기술

- **개발언어:** Python
- **주요 기술:** Windows 파일시스템 탐색 및 데스크톱 UI
- **배포 형태:** 단일 Windows 실행파일(EXE)

## 주요 기능

- 사용자·Windows 임시파일, 캐시, 브라우저 캐시 등 정리 후보 검색
- 파일 유형·위치·예상 정리 용량 표시
- 검색 결과 검토 및 사용자 선택에 따른 파일 삭제
- 중복 파일과 저장공간 관련 탐색
- 저장공간 현황의 3D 시각화
- 대량 작업의 진행률, 완료·건너뜀·실패 결과 표시
- 일반 권한 실행과 필요한 작업에 한정한 권한 안내
